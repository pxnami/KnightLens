# KnightLens

## Platform
web

## Stack
React and TypeScript, approved by the user; static GitHub Pages deployment.

## Purpose
Review chess games imported as PGN or from public Chess.com and Lichess profiles. German and English interface and coaching. Local Stockfish 18 analysis, move categories, accuracy, replay, and alternatives.

## Brand commitments
The user explicitly requested the Chess.com visual treatment from the supplied screenshots, including Neo pieces. Preserve KnightLens identity while matching the charcoal sidebar, blue Icy Sea board, white coach speech bubble, green buttons and compact review panel. Visual assets load directly from official Chess.com image hosts.

## Constraints
No secrets or backend. Proprietary Chess.com classifications cannot be reproduced exactly. Coaching must be derived from the actual position and engine output.
